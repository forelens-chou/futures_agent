🚀 **【AI + 大宗商品】用几行代码搭建一个“白糖行情分析 Agent”！**

做期货投研或企业原材料采购，每天盯天气、刷新闻、看库存是不是太耗时？不如让 AI 帮自动化追踪！

分享一个基于 Google ADK 开发的 **“白糖产业链情报 Agent”** 极简示例，实现从“信息搜集”到“逻辑分析”的全流程自动化 🤖👇

💡 **核心逻辑拆解为 3 步：**

1️⃣ **产业链关键词选择（Tool 模块）**  
Agent 自动调用结构化知识库，将白糖按“国内种植（广西甘蔗/开榨率）”、“国际生产（巴西降雨/印度出口配额 - 支持英文检索）”、“下游消费”和“库存政策”等多维度精准拆解关键词。

2️⃣ **Google 智能搜索（Search 模块）**  
结合“降雨 delay”、“减产”、“限制出口”等价格高敏感词，自动生成精细化 Query，直接向 Google 发起检索，抓取全球第一手动态新闻。

3️⃣ **智能提炼与分析（Analysis 模块）**  
Gemini 过滤无用噪点和重复报价，自动梳理上下游的价格传导逻辑，最终输出一份结构化的行情研报！

---

🛠️ **架构亮点：**
- **代码解耦**：Agent 逻辑与 Tool 工具库独立分离，可维护性强。
- **一键复用**：替换映射字典，就能秒级拓展到纸浆、纯碱、烧碱等其他大宗商品！
